# 🟢 Vexora System Status Page

Welcome to the open-source uptime monitoring repository for **Vexora IT Solutions**. This status page is automatically updated using **GitHub Actions**, **GitHub Issues**, and **GitHub Pages**.

## 🔗 Quick Links

- **Live Status Page:** [status.vexorait.com](https://status.vexorait.com)
- **Main Website:** [vexorait.com](https://vexorait.com)

## 📡 Monitored Infrastructure

- **Vexora Web Portal** (`https://vexorait.com`)
- **Vexora Core API Gateway** (`https://api.vexorait.com`)

## ⚙️ How It Works

- **Uptime Check:** GitHub Actions run every 5 minutes to test service response times.
- **Incident Reports:** If a service goes down, a GitHub Issue is automatically created to display alerts on the live page.
- **No Server Required:** Powered 100% by GitHub's infrastructure.
